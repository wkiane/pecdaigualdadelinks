# Linktree (QR code) — PEC da Igualdade LGBT

Página estática de links, em HTML e CSS puros, sem JavaScript e sem build.

## Conteúdo

- `index.html` — a estrutura e o conteúdo da página.
- `style.css` — os estilos. As cores e fontes ficam em variáveis no `:root`.

As fontes (Anton e Raleway) vêm do Google Fonts, então a página depende de
acesso a `fonts.googleapis.com` para aparecer com a tipografia certa.

## Visualização

Abra o `index.html` direto no navegador ou sirva a pasta com
`python3 -m http.server`.
